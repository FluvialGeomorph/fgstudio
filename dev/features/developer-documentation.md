# Developer documentation and navigation

ADR 0006 requires human and agent development to remain interchangeable. Articles
explain events, callbacks, state and persistence; compact agent routes identify
first source/test files and fluvgeo boundaries. Numbered articles follow the app
workflow, with developer-only facilities outside that sequence.

Pkgdown builds the local reference, articles and text exports. flow diagrams are
embedded as HTML widgets. pkgnet supplies static package dependencies; reviewed
source bridges identify important indirect calls. The generated JSON records
source hashes and distinguishes static edges from reviewed bridges. It does not
claim complete runtime or cross-repository coverage.

The documentation workflow specifies paired maintenance and present-tense
consolidation. Standard checks verify freshness, lookup, bridge anchors, article
navigation and local links. The navigation pilot is optional evaluation evidence;
it establishes no measured speed or context-budget advantage. Documentation
packages remain development dependencies rather than runtime Imports.
